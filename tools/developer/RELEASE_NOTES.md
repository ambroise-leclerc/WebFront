Browser-powered WebFront developer environment and PI starter, versioned separately from the C++ library.

Download the environment and starter through the version-pinned GitHub Pages URLs in the bootstrap configuration. The application verifies SHA-512 before executing the environment or creating the starter. React, React DOM and scheduler remain on npm; developers do not install Node.js or npm.

The archive includes the terminal, npm resolver, esbuild/WASM compiler, embedding tools and dependency notices. The starter contains editable PI TSX/CSS and an exact dependency recipe. The environment and starter are experimental; browser packages only, without installation scripts, native modules or Node API shims.
